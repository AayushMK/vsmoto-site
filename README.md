# VS Moto

Website for VS Moto, custom bike graphics by Vivek Shahi.

## Run it locally

    python3 -m http.server 4330

Then open http://localhost:4330

## Change things

- **Instagram posts in the Work section:** open `app.js`, edit the `POSTS` list at the top.
  Paste any public post or reel link from @vs.moto_2046.
- **Words:** everything is in `index.html`.
- **Colours:** top of `styles.css`.

## Before going live

- Rewrite the "Who's behind it" section in Vivek's own words (it is placeholder copy).
- Check the services list matches what he actually offers.
- If he wants WhatsApp or a phone number, add it to the Contact section.

## Put it online (GitHub Pages)

1. Create a repo on GitHub and push this folder to `main`.
2. On GitHub: Settings, then Pages, then set Source to "GitHub Actions".
3. Every push to `main` republishes the site in about a minute.
